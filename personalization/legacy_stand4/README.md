# (기록용) 이전 정자세 4방향 체형 피팅 — 재사용하지 마세요

정자세 4방향(앞·오른쪽·뒤·왼쪽) 사진으로 SMPL 체형을 구하던 이전 버전입니다 (II-8 → II-10 → II-12 → II-13 + 진단 II-14 ~ II-17).

**알려진 문제 (2026-10 발견):**

- 왼쪽 뷰 보정값(yaw +10°, x −0.25 m, y −0.08 m)은 이 문제의 증상을 경험적으로 덮은 값으로 보입니다.
